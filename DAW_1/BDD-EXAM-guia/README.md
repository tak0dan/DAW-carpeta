# BDD-EXAM-guia — Bases de Datos study guide

Static HTML study guide for the Bases de Datos exam (open `index.html` in a browser).

## Contents

- `index.html` — entry point
- `mongodb-basico.html`, `mongodb-avanzado.html`, `mongodb-paso-a-paso.html`, `mongodb-updates-arrays.html` — MongoDB units
- `plantillas-listas.html` — templates and lists
- `styles.css` — shared styling

## How this folder relates to others

- Companion of **`../BDD-EXAM/`**: this folder explains the theory, that one drills the exercises.
- Both support the subject in **`../BDD/`**.
