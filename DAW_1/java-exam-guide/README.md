# java-exam-guide — self-built Java study site

A study website built for the Java exam: theory guides, a practice exam and solutions. Open `index.html` in a browser.

## Contents

- `index.html` — entry point
- `guides/` — theory pages: classes & objects, encapsulation & accessors, constructors & initialisation, collections & ArrayList, …
- `exam/` — practice exam, `solutions/` — worked solutions
- `assets/` — shared CSS/JS (`tokens.css`, `layout.css`, `site-data.js`, `exam-page.js`, …)

## How this folder relates to others

- Revision support for **`../PRG/`** and **`../PRG-2/`** (Java coursework).
- Same idea as `../BDD-EXAM-guia/`, but for Programming instead of Databases.
