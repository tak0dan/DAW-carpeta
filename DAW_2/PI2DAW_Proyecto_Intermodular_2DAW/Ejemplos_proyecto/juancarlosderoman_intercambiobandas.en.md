# Promotion exchange tool for bands

*Final project by Juan Carlos de Román Doblas*

## DESCRIPTION

The project consists of the design, creation and adaptation of a website through which the music groups that register can arrange to exchange concerts as well as promotion.

Practical case:

A group from Valencia registers and sees a group of the same musical style or with a compatible audience; it then has an option to propose a concert exchange, i.e. one of the two groups will go and play in the other's city alongside it, and the deal is then closed by doing the same in reverse. (This is very common among groups.)

They will also have other options, such as exchanging advertising on their respective Facebook pages, or simply the option of indicating that they would like to play alongside that group.

## FEATURES

- There will be only 2 types of users: Groups and Administrator.
- Each group's profile will show information such as style, city, Facebook, embedded content (YouTube, SoundCloud, etc.), among other things.

### Administrator

- See whether a group has been "reported" for misconduct or for breaching an agreement.
- See how many times a group has been reported (if applicable).
- Suspend accounts temporarily.
- Suspend accounts indefinitely.

### Group

- View other groups.
- Mark the groups it likes.
- Mark other groups as "friends".
- Request a promotion exchange on the respective Facebook pages.
- Request a concert agreement.
- Declare interest in playing with that group.
- Send a message to another group.
- Mark the groups it has played with, or add them if they are not registered (if the group's e-mail address is provided, they will be notified by e-mail that they have been named).

## TOOLS

- PHP will be used as the main language and MySQL for the database.
- JavaScript will also be used for some features and CSS for the whole graphical part.
- All image and graphics processing will be done in Photoshop.

## DELIVERY

At the end of the project it will be shown uploaded and fully functional on an external server.

All the source code and the database will also be delivered in a text file.
