# Ernesto Micó — PROJECT

The idea is to build a website dedicated to presenting, and later selling, pastry products with made-to-order work.

The idea comes from a relative who does this for a living and needs this website to make their work known and, at the same time, to have a good business opportunity thanks to the possibilities that having a website on the internet offers.

The idea still has a lot of maturing to do and I have many doubts to resolve, but what I am clear this project should include is:

- A home page presenting the business, the person who runs it and the possibilities it offers.
- A photo gallery of the work done, ordered chronologically by event.
- The option to place an order or request information or a quote. I don't know yet whether I will include a shopping cart or simply a contact form, although I think it should have both: a cart for making purchases and a contact form for requesting information. Regarding the cart I would need a lot of help, since we have not built one in class.
- It would have a database with all the information about the products, photos and users (in the case of online purchases they would have to register; at the same time I would keep the details of potential customers who request information through the form).
- I would like to add modules for interacting with social networks, since the business needs to make itself known.
- Regarding the visual side, I have many things to decide, such as using a CMS or some template, since I think the site must be eye-catching (without being overloaded). I would like guidance on this point with respect to using a CMS, HTML and CSS, etc.
- I want to try to make the site as accessible as possible, try to have it display more or less correctly on PCs as well as smartphones or tablets, and try to "control" SEO as far as possible.
- It would have a back end so that the administrator can modify the website (if no CMS is used, I would build it myself).
- Initially I would rent the web server from 1&1, for example, although I find it interesting to set up a web server on a PC at home, either on Linux or on Windows. For this, however, I would need quite a lot of help.
- I am also interested in adding RSS so that people can receive the page's updates in their feed readers.
- I would like to build some kind of function or application that collects the details of potential or existing customers and sends out e-mails in bulk with news, offers…

The programming languages to be used would be the ones seen this year: HTML, CSS, PHP, JavaScript, Ajax…

As for the teacher I would like to supervise me, I have chosen Raúl simply because he is the one we have practised with the most and he taught me almost all the languages I want to use, but I would be very grateful to be able to count on any teacher to resolve any doubt I may have.

I don't know whether you will consider the project substantial enough. I would greatly appreciate your advice and possible improvements, extensions and ideas. For me, having never built a website, it is certainly quite a challenge.
