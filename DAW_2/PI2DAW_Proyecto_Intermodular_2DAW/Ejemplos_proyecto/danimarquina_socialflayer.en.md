# SocialFlyer

*Daniel Marquina Bergad*

## 1. DESCRIPTION

The main goal of the project is the design, development and implementation of a web tool that helps with and simplifies the management of public relations for pubs, nightclubs and companies that organise events — for the employees, for the managers of the various departments, and for the event attendees themselves.

Employees have to sell tickets to customers and thereby earn extra incentives in return. Through this application it will be possible to manage guest lists, know which guests attended the event, what commission each employee receives, etc. In addition, customers themselves will be able to access the application voluntarily and sign up for any of the events the company has scheduled.

## 2. REQUIREMENTS

- PHP will be used as the main programming language, together with JavaScript.
- MySQL will be used as the database management system.
- The application will distinguish between five types of users: customers, employees, managers, point of sale and administrator. Each will access their corresponding sections.
- The functions available to employees will be:
  - Signing up a limited number of people at a given ticket price.
  - Receiving private messages from managers.
  - Employees can share a link with their code on social networks so that customers sign up on that employee's list.
  - Viewing the incentives earned per event.
  - Receiving private messages from the managers.
- The functions available to managers will be:
  - Creating events (title, poster, description, etc.)
  - Assigning different rates per event
  - Downloading guest lists as PDF
  - Sending private messages to employees
- The functions available to customers will be:
  - Customers can sign up on a list from their computer, their mobile phone or an app.
- The functions of the point-of-sale terminal will be:
  - Quick-use POS operated with the keyboard (sale of tickets and other services)
  - Accounting for all possible rates and for admissions to the venue
  - Accounting statement of the income received per event.
- The main features for the administrator will be:
  - Registering employees and managers.
  - Editing and deleting events
  - Administering all the options available to employees, managers and the POS.
