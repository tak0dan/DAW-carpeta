
# FORMATO DE LA ENTREGA ____________________________________________________

1) A continuación he transferido el contenido de "Entrega y presentación de prácticas".

2) Si la entrega de la tarea debe ser un documento PDF, el nombre tendrá el siguiente formato:

    <tu usuario>_p<número de la tarea con dos dígitos>.pdf

    edeperant_p01.pdf

3) Asegúrate que el nombre no contenga la letra ñ, tildes ni caracteres especiales extraños. Así por ejemplo el alumno José Adrián García Tebar para la primera tarea, tendría el siguiente nombre:

    jagarciat_p01.pdf


4) Debe contener:
    1. una *portada*, 
    2. *número* de la tarea, 
    3. *título* de la tarea, 
    4. nombre del *módulo* profesional, 
    5. Nombre del *ciclo* formativo, 
    6. *autor*(es) 
    7. *fecha* de realización.


5) Debe tener un *índice* actualizado con hiperenlaces a las diferentes secciones y el número de página donde están.


6) Debe tener cada página *numerada*.


7) Las actividades deberán estar *numeradas* y ordenadas correctamente.


8) Cada actividad debe tener el enunciado en *negrita* y la respuesta en texto normal.


9) Cada imagen debe tener un texto que la presente o un *pie de foto* con el siguiente formato: 

    Figura <número>: <Breve descripción de la figura>.


10) Los *comandos*, documentos de configuración y código fuente deben quedar reflejados *en el PDF* de la entrega en texto plano para permitir copiar y pegar de una manera rápida.


11) Los *comandos*, documentos de configuración y código fuente que se muestren en el documento PDF deben tener un estilo de letra *monospace* como puede ser el tipo de letra Consolas o Courier New. Por ejemplo: $sudo apt install neofetch.


12) Para las actividades *a mano* se deberá hacer una foto a la resolución del ejercicio y añadirla al PDF.

13) El documento no debe contener *faltas ortográficas*.

14) En el caso de utilizar capturas de toda la pantalla, las *capturas* también deben demostrar la autoría de las actividades. Por lo tanto, estas capturas deberán ser *de toda la pantalla del alumno* para que se vea la fecha de realización y el nombre del fichero que está abierto. Recomiendo encarecidamente la herramienta gratuita *Flameshot* para hacer capturas.

    https://flameshot.org/


15) Si las capturas son de una zona muy específica de la pantalla *no es necesario* hacer lo anterior. Usad el sentido común.


16) Si la entrega de la tarea debe ser un documento ZIP, el *nombre* tendrá el siguiente formato:

    <tu usuario>_p<número de la práctica con dos dígitos>.zip


17) Asegúrate que el nombre no contenga la letra ñ, tildes ni caracteres especiales extraños. Así por ejemplo el alumno José Adrián García Tebar para la primera tarea, tendría el siguiente nombre:

    jagarciat_p01.zip



18) En la raíz del fichero ZIP deberá encontrarse el documento PDF (en el caso que se pida) con el nombre mruizg_t01.pdf y las actividades en el formato que corresponda:

    1. Las actividades de XML deberán estar en formato XML con el nombre <tu usuario>_a<Número de la actividad con dos dígitos>.xml. Por ejemplo: jagarciat_a01.xml.

    2. Las actividades de HTML deberán estar en formato HTML con el nombre <tu usuario>_a<Número de la actividad con dos dígitos>.html. Por ejemplo: jagarciat_a01.html.

    3. Las actividades de Packet Tracer 6.2 deberán estar en formato PKT con el nombre <tu usuario>_a<Número de la actividad con dos dígitos>.pkt. Por ejemplojagarciat_a01.pkt.

    4. Las actividades de JavaScript deberán estar en formato JS con el nombre <tu usuario>_a<Número de la actividad con dos dígitos>.js. Por ejemplo: jagarciat_a01.js.

    5. Las actividades con otro tipo de extensión deberán estar en formato correspondiente <tu usuario>_a<Número de la actividad con dos dígitos>.<extensión>. Por ejemplo: jagarciat_a01.jar.
