INTRODUCTION
The Web Application Deployment module, taught in the second year of the Higher Degree Cycle
in Web Application Development, aims for students to achieve the following terminal
competences:
    a) Implement web architectures by analysing and applying functionality criteria.
    b) Manage application servers, adapting their configuration in each case to allow the
        deployment of web applications.
    c) Implement web applications on application servers, evaluating and applying
        configuration criteria for their secure operation.
    d) Produce and maintain the documentation of development processes, using
        documentation generation and version control tools.
    e) Deploy and distribute web applications in different implementation environments,
        verifying their behaviour and making modifications.
    f) Manage and/or carry out the maintenance of the resources of their area according to
        workloads and the maintenance plan.
    g) Administer file transfer servers, evaluating and applying configuration criteria that
        guarantee service availability.

2. CONTENTS
The teaching units to be delivered are:

UT1: Implementation of web architectures
UT2: Administration of web servers
UT3: Administration of application servers
UT4: Installation and administration of file transfer servers
UT5: Network services involved in the deployment of a web application
UT6: Documentation and version control systems
UT7: CMS
UT8: Clouding

Below is a detailed breakdown of the contents that will make up each of the teaching units.

UT 1: Implementation of web architectures

- Web architectures. Models.
- Web and application servers. Basic installation and configuration.
- Structure and resources that make up a web application. Deployment descriptor.

UT 2: Administration of web servers

- Advanced configuration of the web server.
- Modules: installation, configuration and use.
- Virtual hosts. Creation, configuration and use.
- Authentication and access control.
- The HTTPS protocol.
- Certificates. Certificate servers.
- Deployment of applications on web servers.

UT 3: Administration of application servers

- Architecture and basic configuration of the application server.
- Managing web applications.
- User authentication. Security domains for authentication.
- Session management. Persistent sessions.
- Access log files and request filtering.
- Configuration of the application server to cooperate with web servers.
- Deployment of applications on the application server.
- Security on the application server. Server configuration with SSL/T support.

UT 4: Installation and administration of file transfer servers

- Configuration of the file transfer service. Permissions and quotas.
- Types of users and access to the service.
- Client connection modes.
- Secure file transfer protocol.
- Use of graphical tools.
- Use of the file transfer service from the browser.
- Use of the file transfer service in the web application deployment process.

UT 5: Network services involved in the deployment of a web application

- Name resolvers. Process of resolving a domain name.
- Name server configuration parameters and records affected during deployment.
- Directory service: features and functionality.
- Basic configuration files. Interpretation and use.
- User authentication in the directory service.
- Adaptation of the directory server configuration for the deployment of the application.

UT 6: Documentation and version control systems

- External tools for documentation generation. Installation, configuration and use.
- Creation and use of templates.
- Installation, configuration and use of version control systems.
- Advanced operations.
- Security of version control systems.
- History of a repository.

UT 7: CMS

- WordPress.
- MediaWiki.
- Moodle.
- Joomla.
- Prestashop.
- Drupal.

UT 8: Clouding

Use of commercial clouding systems for the deployment of web applications.

5. METHODOLOGY
The methodology to be followed will consist of presenting a set of concepts of the subject
matter of learning on the whiteboard or using the projector. Afterwards, related problems or
activities will be proposed, with the aim of helping the student to better assimilate the
contents. Supplementary material will be used: a selection of exercises or theory to
complement the explanations, and recommended bibliography on those points the teacher
deems appropriate, in paper or electronic format.

Given the essentially procedural nature of the subject, various exercises and practicals
associated with each of the units will be proposed and solved in class. While the students are
doing the exercises, the teacher will deal with any doubts that may arise and explain additional
concepts that may be of help. In each of the thematic units, additional activities will be offered
to those students who require them.

Considerations in the event of suspension of in-person teaching or division of the group

If in-person teaching is suspended, students will carry out the teaching-learning activities of
the lesson/subject remotely.

To this end, the following tools provided by the Regional Ministry of Education will be used to
carry out the distance-learning process and student monitoring:

• Aules platform: it allows us to create virtual classrooms to complement in-person classes and
  monitor the distance-learning process, as well as to comply with data protection regulations,
  since the information always resides on servers owned by the Generalitat (regional
  government).

• WebEx platform: it is the Regional Ministry of Education's official tool for video
  conferencing. This tool is proposed for delivering live teaching. Access will be through a
  permanent, unique URL link for each teacher.

• E-mail: e-mail will preferably be used for communication with students.

If in-person teaching is not suspended, but the group must be split in two to guarantee hygiene
and safety measures, part of the work will be carried out remotely using the tools mentioned
above.

In both cases, the fundamental contents of the lesson will be prioritised in order to achieve its
minimum objectives.

6. ASSESSMENT CRITERIA
The student will pass the subject when achieving a grade of "apt" (pass) in both the
theoretical and practical tests that will be held each term and which will be used to evaluate
the knowledge acquired during that academic period. The theoretical and practical exercises
must be passed and submitted on the dates set by the teacher. Compensation is considered at 4
(between the practical and the theory mark).

It will be necessary to have submitted and passed the module project of the subject.

8. CROSS-CURRICULAR THEMES
The royal decrees that have established the curricula of the different educational stages define
a series of teachings that must be present in the different subject areas. For the Ministry of
Education and Science, speaking of cross-curricular teaching is not about introducing new
contents that are not already reflected in the subject curricula, but rather about organising some
of those contents around a given educational axis. The reason for the presence of cross-
curricular themes in the curriculum is strongly justified both for the personal and integral
development of students and for a project of a freer society that is more respectful of people
and of the human environment.

The presence of attitudes and values has been structured around the following cross-curricular
themes:
  • Education for equal opportunities for both sexes.
  • Education for peace.
  • Environmental education.

The presence of cross-curricular themes in the curriculum development is the responsibility of
the entire educational community, especially of the teaching staff, which is why they must be
present in the school's educational project, in the stage curriculum project and in the teaching
programmes.

In the case at hand, since this is a vocational training module, the cross-cutting nature of its
contents affects students differently from those taking general education courses. Given that it
is vocational training, it is very difficult to incorporate cross-curricular themes such as health
education, peace, consumer education, etc. into the curriculum. We believe that it is in the
classroom development that values and behaviours, as well as their learning, must be
addressed; this type of element forms part of what is known as the hidden curriculum.

The role played by the teacher in the field of values is decisive, both as regards their personal
attitude and in the organisation and management of the students' activities within the
educational centre. Although the decrees establishing the curriculum of the training cycles have
not incorporated cross-curricular themes, from the training cycle in question and, more
specifically, from the module being programmed, the objective is the development of the
integral personality, using a globalising method that puts into practice the capacities and
attitudes we want for our students: relationship with the environment as a framework, resource
and objective; active participation; cooperation; acceptance of responsibilities; critical
analysis; commitment and action; problem solving.

10. MEASURES FOR ATTENTION TO DIVERSITY
Students who, whether due to their ability or their experience, have a level clearly higher than
the rest of the class will be offered specific activities that allow them to develop their intellect
in the most appropriate way, with recommendations to read on specific topics taken from the
internet, magazines or books on the subject, and being given more complex exercises than the
rest of the class.

Those who have a level clearly below the class average will be guided towards carrying out the
most basic activities that meet the objectives set for the module. They will be provided with
support information appropriate to their level and will be guided so that they can install and use
the same teaching material given at the centre.

Students who suffer from some type of disability that prevents them from properly developing
the concepts covered in class will be provided with all kinds of measures designed to ensure
that the student achieves the minimum objectives of the module.
