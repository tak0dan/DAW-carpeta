
# INTRODUCCIÓN ______________________________________________________

1) Siglas de la asignatura = DAW = Desarrollo de Aplicaciones Web. 


2) CMS.

    1. CMS significa Content Management System, es decir, Sistema de Gestión de Contenidos.

    2. Es un software que permite crear, gestionar y modificar contenido de una web sin tener que programarlo todo desde cero.

    3. WordPress -> aplicación CMS ya construida para gestionar contenido.

    4. Por ejemplo, si una empresa quiere una web corporativa sencilla, puede usar WordPress y configurar el contenido.

    5. Pero si quiere una aplicación web con una lógica específica —por ejemplo, un sistema de gestión de laboratorios, reservas, usuarios, inventario, etc.— puede tener sentido desarrollarla con Laravel.
