1. Posicionamiento CSS UD5.1

La propiedad position controla cómo y dónde se coloca una caja HTML. Las propiedades top, right, bottom, left desplazan el elemento según el tipo de posicionamiento activo.

Los 5 tipos de posicionamiento

ValorSale del flujoReferenciaDescripción
static❌ No—Por defecto. top/left/right/bottom se ignoran
relative❌ No (hueco queda)Su posición originalSe desplaza respecto a donde estaría normalmente
absolute✅ SíPrimer ancestro posicionado (no static)Sale del flujo. El resto ocupa su sitio
fixed✅ SíVentana del navegadorInamovible al hacer scroll
sticky⚡ MixtoFlujo → ventana al llegar al umbralRespeta el flujo hasta que alcanza el umbral

Posicionamiento relativo

El elemento no sale del flujo. El hueco original se mantiene. El desplazamiento es relativo a su posición normal. top mueve hacia abajo, left hacia la derecha.

⚠️
Importante
Con position: relative el hueco original siempre se mantiene aunque el elemento se desplace visualmente.
position: relative
img.desplazada {
  position: relative;
  top: 8em;     /* mueve 8em hacia ABAJO */
  left: 20px;   /* mueve 20px hacia la DERECHA */
}

/* Valores negativos = dirección contraria */
img.subida {
  position: relative;
  top: -20px;   /* mueve hacia ARRIBA */
}

Posicionamiento absoluto

La caja sale del flujo. El resto de elementos se mueven para ocupar su lugar. La referencia se determina así:

  1. Se busca el primer ancestro posicionado (que NO sea static)
  2. Si ninguno está posicionado → la referencia es la ventana del navegador
💡
Truco esencial del examen
Para que un absolute se posicione dentro de un div, ese div debe tener position: relative. Este patrón es muy habitual en exámenes.
absolute dentro de contenedor relativo
/* El contenedor es la referencia */
div.contenedor {
  position: relative;   /* ← hace de "contenedor posicionado" */
  border: 2px solid #CCC;
  padding: 1em;
  width: 300px;
}

/* El hijo se posiciona respecto al div */
div.contenedor img {
  position: absolute;
  top: 50px;
  left: 50px;
}

Posicionamiento fijo

Como absolute pero la referencia es siempre la ventana del navegador. El elemento permanece inamovible aunque el usuario haga scroll. Típico uso: menú de navegación.

position: fixed — menú siempre visible
nav.menu {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
  background: #333;
  color: #fff;
  z-index: 1000;   /* Encima de todo */
}

2. Float · Clear · Overflow UD5.1

float desplaza una caja todo lo posible hacia la izquierda o derecha. El texto de los elementos adyacentes fluye a su alrededor.

display: none → elimina el espacio, el resto se mueve. visibility: hidden → el elemento es invisible pero el hueco queda.
display vs visibility — JavaScript
/* Oculta y DEJA el hueco (invisible pero ocupa espacio) */
element.style.visibility = 'hidden';
element.style.visibility = 'visible';  /* Restaurar */

/* Oculta y NO deja hueco (el resto se expande) */
element.style.display = 'none';
element.style.display = 'block';       /* Restaurar */

/* En CSS directamente */
.oculto-con-hueco  { visibility: hidden; }
.oculto-sin-hueco  { display: none; }

5. Flexbox UD5.2

Flexbox es un sistema de diseño que permite distribuir y alinear elementos de forma flexible. Se activa con display: flex en el contenedor padre.

Conceptos básicos

📦 Contenedor flex
El elemento padre con display: flex. Las propiedades de alineación se aplican aquí.
→ Eje principal
Por defecto horizontal (fila). Lo controla flex-direction.
↓ Eje secundario
Perpendicular al principal. Vertical por defecto.
🔲 Ítem flex
Cada hijo directo del contenedor. Las propiedades de ítem van aquí.

💡
gap — sin margin en hijos
gap (o row-gap / column-gap) establece el hueco entre ítems directamente desde el contenedor. Más limpio que usar margin en los hijos.
gap · row-gap · column-gap
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 4px 8px;
  /* Equivalente a:
     row-gap: 4px;
     column-gap: 8px; */
}

/* Mismo gap en ambos ejes */
gap: 16px;

6. Transiciones CSS UD5.2

Las transiciones CSS permiten que los cambios de propiedades ocurran de forma gradual y suave en lugar de forma instantánea. Se combinan con pseudoclases como :hover.

ℹ️
Sintaxis básica
transition: propiedad duración; — Por ejemplo: transition: background 2s; o transition: all 0.5s;

Transición de entrada y salida

Se controla dónde se coloca la propiedad transition:

transition en A (elemento)
Se ejecuta tanto al entrar como al salir del hover.
transition en B (:hover)
Se ejecuta solo al entrar al hover. Al salir el cambio es brusco.
transition en A y en B
Se ejecuta en ambos sentidos, pero la duración total se suma (2s + 2s = 4s).
Transiciones — casos de uso
/* Caso 1: transición en A → entra Y sale con transición */
.element {
  background: red;
  transition: 2s;   /* ← En A */
}
.element:hover {
  background: blue;
}

/* Caso 2: transición en B → solo entra con transición */
.element {
  background: red;
}
.element:hover {
  background: blue;
  transition: 2s;   /* ← En B */
}

/* Caso 3: transición solo en hover */
.element { background: red; }
.element:hover { background: blue; }

Transiciones por propiedad

Diferentes duraciones por propiedad
.element {
  width: 200px;
  height: 200px;
  background: grey;
  transition:
    width 4s,         /* El ancho tarda 4 segundos */
    background 1s;    /* El color tarda 1 segundo */
}
.element:hover {
  width: 400px;
  background: deeppink;
}

/* También se puede: */
transition: all 0.5s;   /* Todas las propiedades a la vez */

Prácticas UD5.1 + UD5.1B

UD5.1 Práctica — Float + Display + Position

Recopila float, overflow, clear, visibility, display, position fixed y @media queries:

  1. Barra de menú fija — position: fixed; top: 0; El menú no se mueve al hacer scroll. Al pasar el cursor, subrayado azul y fondo naranja.
  2. Capa con visibility — Desaparece con visibility: hidden. Deja el hueco. Son capas con float. JS: element.style.visibility = 'hidden'
  3. Capa con display — Desaparece con display: none. NO deja hueco, la caja de la derecha se expande. JS: element.style.display = 'none'
  4. Capa estilo menú pero sin fixed — Desaparece al pulsar, pero al hacer scroll se desplaza (no es fixed).
  5. Responsive con @media
Código base de la práctica UD5.1
/* Menú fijo */
nav { position: fixed; top: 0; left: 0; width: 100%; z-index: 1000; }
nav a:hover { text-decoration: underline; color: blue; background: orange; }

/* Capa con float + visibility */
.imageLeft  { float: left; }
.imageRight { float: right; }
.clear      { clear: both; }

/* Botones del enunciado */
/* Visibility: deja hueco */
onclick="document.getElementById('imageLeft').style.visibility = 'hidden'"

/* Display: NO deja hueco */
onclick="document.getElementById('imageToHide').style.display = 'none'"

/* Overflow en contenedor */
.caja-scroll { overflow-y: scroll; overflow-x: hidden; height: 150px; }

UD5.1B Práctica Extra — Float

Maquetación completa con float. La web de la empresa puede ser lo que quieras:

  1. Menú superior fijo — Siempre en la parte superior aunque uses el scroll.
  2. Título empresa — Debajo se ve el fondo de la página que NO se desplaza (background-attachment: fixed).
  3. Capa cookies — Aparece a mitad de página. Desaparece al pulsar el botón (como la semana pasada).
  4. Zona central — Dos capas de información. La primera: imagen a la derecha. La segunda: imagen a la izquierda.
  5. Menú lateral flotante a la derecha — Lista con imágenes clickables.
  6. Pie de página — Con información de la empresa.
  7. Los enlaces se subrayan al pasar el cursor (a:hover { text-decoration: underline; }).
  8. Responsive — En móvil, el menú lateral (capa 5) pasa a verse horizontalmente debajo de la capa 4.
Estructura base UD5.1B
/* Menú fijo */
nav.menu { position: fixed; top: 0; width: 100%; z-index: 999; }

/* Fondo que no se desplaza */
.header-empresa { background-attachment: fixed; }

/* Capa cookies */
.cookies { position: fixed; bottom: 0; left: 0; right: 0; }
.cookies button { } /* Pulsar → element.style.display = 'none' */

/* Zona central */
.zona-central { overflow: auto; }  /* Limpia los floats */
.col-info-1 img { float: right; margin-left: 12px; }
.col-info-2 img { float: left;  margin-right: 12px; }

/* Menú lateral derecha */
.menu-lateral { float: right; width: 200px; }
.menu-lateral img { display: block; width: 100%; }

/* Footer */
footer { clear: both; }

/* Links */
a:hover { text-decoration: underline; }

/* Responsive — móvil */
@media (max-width: 768px) {
  .menu-lateral {
    float: none;         /* Deja de flotar */
    display: flex;       /* Pasa a horizontal */
    width: 100%;
  }
}
