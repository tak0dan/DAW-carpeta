2. Are all single-processor systems single-task?
Are all multiprocessor systems multitasking?

No. A single-processor system can be multitasking if the OS shares CPU time between processes.

No. A multiprocessor system could run only one task, although almost all modern ones are multitasking.

3. What is an interface?

An interface is a communication method between two parts.
It allows systems, programs, or users to exchange information clearly.
