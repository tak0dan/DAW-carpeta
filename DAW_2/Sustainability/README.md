# Sostenibilitat aplicada al sistema productiu

*English: Sustainability applied to the productive system*

**Academic year:** 2026/27
**Group:** 2CFSD

## Folder structure

| Folder | What goes here |
|---|---|
| `Class_Material/` | Slides, notes and other material from class |
| `Homework/` | Assigned homework |
| `Practices/` | Practice exercises |
| `Projects/` | Projects, in the required format |
| `Original_Material/` | Source material in its original format |
| `Translated_Material/` | My translations of that material |
| `Classmate_Solutions/` | Solution examples made by classmates |
| `My_Solutions/` | My own solutions |

## How the folders relate

All eight folders form one workflow:

1. **`Class_Material/`** — material received in class (the starting point).
2. **`Original_Material/`** — that material kept in its **original format**; never edited.
3. **`Translated_Material/`** — **your translations**, derived from `Original_Material/` (the originals stay untouched).
4. **`Practices/`** — exercises based on that material; your own attempts go to **`My_Solutions/`**.
5. **`Classmate_Solutions/`** — solution examples made by classmates, to compare against **`My_Solutions/`**.
6. **`Homework/`** — assigned, graded work · **`Projects/`** — larger final projects pulling everything together.

**Related:** common second-year module with no subject-specific siblings; use the same `Original_Material/` → `Translated_Material/` workflow as its sibling courses.
