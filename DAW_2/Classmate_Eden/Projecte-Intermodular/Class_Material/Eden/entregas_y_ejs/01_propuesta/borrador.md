# ACLARANDO IDEAS _______________________________________________________________

## Justificación del alcance -----------------------------------------------------

- El proyecto se ha planteado desde el principio con un alcance reducido y realista, *teniendo en cuenta el tiempo disponible* y que debe desarrollarse simultáneamente con el resto de asignaturas del curso. 

- La versión inicial se centrará en las funcionalidades fundamentales de la aplicación: 

    1. registro e inicio de sesión de usuarios
    
    2. creación y gestión de anuncios
    
    3. consulta de anuncios publicados 
    
    4. búsqueda o filtrado de partidas según diferentes criterios. 
    

- Los anuncios podrán incluir medios de contacto externos, como una dirección de correo electrónico o un usuario de Discord, de manera que los interesados puedan ponerse en contacto directamente *sin necesidad de implementar un sistema de mensajería propio*.

    - De esta forma, la versión inicial ya permite completar el objetivo principal de la aplicación: facilitar que jugadores y grupos encuentren partidas y personas con las que jugar. 


- Las funcionalidades más avanzadas se considerarían ampliaciones para desarrollar únicamente si el tiempo disponible lo permite. 

    - Entre ellas podrían encontrarse un sistema de mensajería interna, solicitudes para unirse a partidas, valoraciones de jugadores y directores de juego, notificaciones o un sistema de perfiles más completo. 
    

- Esto permite disponer primero de una versión funcional y viable y ampliar progresivamente el proyecto sin poner en riesgo su finalización.







# BORRADOR ______________________________________________________________________


1) Título del proyecto:

    RolMatch: plataforma web para encontrar jugadores y partidas de rol



2) Resumen:

El proyecto consiste en desarrollar una aplicación web orientada a jugadores y directores de juegos de rol, como Dungeons & Dragons u otros sistemas. La plataforma permitirá publicar anuncios para buscar jugadores, cubrir plazas vacantes en partidas o encontrar un director de juego. Los usuarios podrán consultar los anuncios publicados y buscar partidas que se ajusten a sus preferencias, como el sistema de juego, el tipo de partida o el rol que desean desempeñar.

La aplicación contará con usuarios registrados que podrán crear y gestionar sus propios anuncios, así como consultar los publicados por otros usuarios. Cada anuncio podrá incluir información sobre la partida, las plazas disponibles, los roles o personajes que se buscan, la experiencia requerida y otros datos relevantes para que los interesados puedan ponerse en contacto con el grupo.



3) Tecnologías empleadas:

Lenguaje de programación: PHP
Framework: Laravel
Sistema de bases de datos:MySQL
