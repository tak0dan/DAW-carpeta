# Respuesta ___________________________________________________________________________


En XAMPP, ese archivo PHP debe estar dentro de la carpeta que Apache utiliza como raíz de documentos.

Por defecto, en Windows es:

C:\xampp\htdocs\

Por tanto, si quieres acceder mediante:

http://localhost/t2/holamundo.php

la estructura debe ser:

C:\xampp\
└── htdocs\
    └── t2\
        └── holamundo.php

Es decir, t2 es una carpeta dentro de htdocs, y dentro de ella colocas holamundo.php.

Después
Abres el XAMPP Control Panel.
Inicias Apache.
El ordenador sirve los archivos que estén en htdocs.
En el navegador escribes:
http://localhost/t2/holamundo.php

Apache busca:

C:\xampp\htdocs\t2\holamundo.php

y ejecuta el PHP antes de enviar el resultado al navegador.

Así que el archivo completo quedaría:

<html>
<head>
<title>Primer ejemplo</title>
</head>
<body>
<h1>Primer ejemplo: <br/></h1>
<?php
echo "Hola mundo.";
?>
</body>
</html>

La idea clave es: *localhost apunta a htdocs; el resto de la URL reproduce la ruta que hay dentro de esa carpeta*.
